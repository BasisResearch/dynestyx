# Scoring Configs

`dynestyx.configs.scoring` contains configuration for evaluating conditioned results. `ObservationScoringConfig` currently configures one-step-ahead predictive-observation scoring.

The score rule objects themselves live on the companion [Scoring](../evaluation/scoring.md) page.
